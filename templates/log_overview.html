log_action() 工具函数 + 12个关键埋点
3.1 log_action() 函数工作流程
1
调用入口
业务代码一行调用
log_action(action,target,detail)
2
自动采集
从 session 取 user_id/username
从 request 取 remote_addr
3
写入数据库
创建 OperationLog 对象
db.session.add + commit
4
容错保护
try-except 静默跳过
绝不中断主业务流程
核心代码：
def log_action(action, target='', detail=''):
  # 1. 非请求环境跳过（命令行/定时任务）
  if not has_request_context(): return
  try:
    user_id = session.get('user_id')   # 自动获取
    username = session.get('username', '')
    ip = request.remote_addr or ''
    log = OperationLog(user_id=..., username=...,
        action=action, target=..., detail=..., ip=...)
    db.session.add(log); db.session.commit()  # 写库
  except: pass  # 日志失败不影响业务

📄 app.py — 认证相关 (3处)
· 登录成功 → log_action('登录成功', username, ...)
· 登录失败 → log_action('登录失败', username, ...)
· 退出登录 → log_action('退出登录', '', '')
📄 blueprints/employee.py — 员工管理 (3处)
· 新增员工 → log_action('新增员工', emp_id, ...)
· 编辑员工 → log_action('编辑员工', emp_id, ...)
· 删除员工 → log_action('删除员工', emp_id, '')
📄 blueprints/predict.py — 预测+报告 (6处)
· 单次预测 → log_action('单次预测', ...)
· 批量预测 → log_action('批量预测', ...)
· 生成报告 → log_action('生成报告', ...)
· 下载报告 → log_action('下载报告', ...)
· 发送邮件 → log_action('发送报告邮件', ...)
· 添加干预 → log_action('添加干预记录', ...)
📄 blueprints/user.py — 用户管理 (2处)
· 创建用户 → log_action('创建用户', username, ...)
· 修改密码 → log_action('修改密码', username, '')
