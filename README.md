# 员工离职预测与风险管理决策支持系统

基于 Flask 的员工离职预测与风险管理决策支持系统。

## 项目结构

- `flaskproject(1)/flaskproject/` - Flask 应用主目录
  - `app.py` - 应用入口
  - `blueprints/` - 蓝图模块
  - `models/` - 机器学习模型
  - `analysis/` - 数据分析
  - `static/` - 静态资源
  - `templates/` - 模板文件
  - `项目文档/` - 项目文档
  - `演示演讲稿.md` - 演示演讲稿

## 运行方式

```bash
cd flaskproject(1)/flaskproject
pip install -r requirements.txt
python app.py
```
