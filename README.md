# 员工离职预测与风险管理决策支持系统

> 基于机器学习的员工离职风险预测与智能决策支持平台，助力企业人力资源数字化转型。

## 项目简介

本项目针对企业员工流失问题，构建了一套集**数据采集、特征工程、模型训练、风险预测、可视化分析、决策建议**于一体的完整系统。通过对员工个人信息、工作状态、薪酬福利、满意度等多维度数据进行建模，实现离职风险的提前预警，并提供可解释的风险因素分析与干预建议。

## 技术栈

| 类别 | 技术 |
|---|---|
| 后端框架 | Flask、SQLAlchemy |
| 机器学习 | scikit-learn、pandas、numpy |
| 数据可视化 | ECharts、Matplotlib、Seaborn |
| 前端 | HTML、CSS、JavaScript、LayUI |
| 数据库 | SQLite |
| 模型算法 | 逻辑回归、随机森林、XGBoost |
| 报告生成 | python-docx、python-pptx、ReportLab |

## 核心功能

- **员工信息管理**：员工数据的增删改查与批量导入
- **离职风险预测**：基于机器学习模型对员工离职概率进行实时预测
- **多模型对比**：支持逻辑回归、随机森林等多种算法的效果对比与选择
- **风险因素分析**：通过特征重要性分析，识别影响离职的关键因素
- **可视化看板**：交互式数据看板，展示离职率分布、部门对比、趋势分析等
- **决策建议生成**：根据风险等级自动生成个性化干预建议
- **报告自动导出**：一键生成分析报告（PDF/Word/Excel/PPT）

## 项目亮点

- **全流程闭环**：从数据清洗、特征工程、模型训练到 Web 部署、可视化、报告生成，覆盖机器学习项目完整生命周期
- **可解释性**：不仅给出预测结果，还通过特征重要性、因子分析提供可解释的决策依据
- **工程化实践**：采用 Flask 蓝图模块化架构，代码结构清晰，具备良好的可维护性
- **多维度分析**：结合描述性分析、诊断性分析、预测性分析，提供全方位的数据洞察

## 项目结构

```
├── app.py                  # 应用入口
├── blueprints/             # 蓝图模块（dashboard、employee、predict、user）
├── models/                 # 训练好的机器学习模型（pkl）
├── analysis/               # 数据分析与模型训练脚本
├── report/                 # 报告生成模块
├── reports/                # 生成的报告（PDF、Excel、图片）
├── output/                 # 分析输出（图表、CSV）
├── static/                 # 静态资源（CSS、JS、字体、图片）
├── templates/              # HTML 模板
├── utils/                  # 工具函数
├── db_model.py             # 数据库模型
├── requirements.txt        # 依赖清单
└── README.md
```

## 快速开始

```bash
# 安装依赖
pip install -r requirements.txt

# 启动应用
python app.py
```

启动后访问 `http://127.0.0.1:5000` 即可使用系统。

## 数据集

使用 IBM HR Analytics Employee Attrition & Performance 数据集，包含 1470 条员工记录、35 个特征字段，涵盖员工人口统计学特征、工作属性、薪酬福利、工作满意度等维度。
